# MusicXML2SVG Viewer

A simple React app for visualizing MusicXML files using OpenSheetMusicDisplay (OSMD).

This app has nothing to do with the midi2musicxml software. It is just to learn about the MusicXML format.

This folder will be removed some day.

## Installation

```bash
npm install
```

## Start

```bash
npm run dev
```

## Usage

1. Select a MusicXML file from the dropdown menu
2. The notation will be automatically rendered in the browser
